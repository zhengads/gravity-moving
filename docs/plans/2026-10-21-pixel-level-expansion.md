# 像素关卡扩充与引导

目标：在现有单文件 HTML 游戏上，移除常驻重力方向显示，扩至五个视觉和物件组合各异的房间，加入逐关机关、猫咪开场对话与短像素过场。保留手机体感、按钮操作、音效和单文件交付。

1. 调整界面：去掉场景和控制区中的重力方向组件，保留按钮按压、场景脉冲、物理运动和辅助技术可读的方向信息。重新排布双按钮，移动端无溢出。
2. 扩充关卡数据与像素画：五个房间逐步增加目标物件，家具类型与装饰不重复；后期有可触发的开关和阻挡收纳通道的门。更新关卡选择和完成文案。
3. 增加进场体验：操作方式选择后由同一只像素猫通过逐句对话介绍规则；关卡切换有猫咪动画、关卡提示和短过场，期间暂停物理模拟与操作。
4. 验证：重建 HTML，运行静态与浏览器交互测试，确认五关可以正常完成、机关能触发、响应式和体感映射无回归；目视检查手机画面。再同步根目录单文件并发布到已有 GitHub Pages。

## 2026-10-21 关卡互动与难度调整

用户试玩后指出第 3–5 关反复使用同一扇门，场景互动和关卡难度不足。保留五间房与单文件 HTML，调整如下：

1. 书房：保留必须绕过的书架，在书架右侧加入会摆动的吊灯碰撞体；绘制吊线与灯罩。物件受碰撞改变路线，玩家需观察摆动时机。验证灯会移动、碰撞有效，第二关仍可把球和书送进箱子。
2. 客厅：保留木块碰高处橙色开关、门升起的独特机制，不改变已有通关口径。验证开关触发、撤销与重来均正确。
3. 厨房：去掉门和重复的木块开关，料理台前加入弹簧垫；上下橱柜之间留出可通过的窗口，避免只需走天花板的直线捷径。物件踩上去时有向上和向右的物理冲量、压缩动画和独立音效。验证三种目标物都能触发、可收纳、重来清空状态。
4. 工作间：去掉门和木块开关，工作台后加入悬挂工具架与每隔数秒自行换向的传送带。工具架使上方绕行受阻，物件需经过传送带下方的通路。玩家只改变重力，并观察箭头和周期条来选择让物件落下的时机；传送带确实改变接触物件的水平速度。验证自动换向、重来后的周期、箭头与物理同步，以及四件目标物可完成。按用户补充要求，不增加任何手动机关按钮或操作杆。
5. 更新关卡标题、提示、设置选关和玩法说明，避免仍称所有关卡都是开门。重建并在手机／桌面浏览器核验画面无溢出和异常；同步根目录单文件，再发布现有 Pages 链接。

这些互动增加可观察的物理和时机决策，但不设失误次数或计时惩罚。玩家始终只操作重力，顺应自动运动的环境解题。

## 2026-10-21 字体补充

根据试玩反馈，统一游戏标题、开场、设置、结算及提示的中文字体，缩小关卡标题的视觉重量，避免早期展示字体在移动端显得夸张。手机保持竖屏游玩；按竖屏坐标映射体感方向，并检查 320px、390px、430px 移动端布局。
