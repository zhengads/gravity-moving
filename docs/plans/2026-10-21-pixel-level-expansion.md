# 像素关卡扩充与引导

目标：在现有单文件 HTML 游戏上，移除常驻重力方向显示，扩至五个视觉和物件组合各异的房间，加入逐关机关、猫咪开场对话与短像素过场。保留手机体感、按钮操作、音效和单文件交付。

1. 调整界面：去掉场景和控制区中的重力方向组件，保留按钮按压、场景脉冲、物理运动和辅助技术可读的方向信息。重新排布双按钮，移动端无溢出。
2. 扩充关卡数据与像素画：五个房间逐步增加目标物件，家具类型与装饰不重复；后期有可触发的开关和阻挡收纳通道的门。更新关卡选择和完成文案。
3. 增加进场体验：操作方式选择后由同一只像素猫通过逐句对话介绍规则；关卡切换有猫咪动画、关卡提示和短过场，期间暂停物理模拟与操作。
4. 验证：重建 HTML，运行静态与浏览器交互测试，确认五关可以正常完成、机关能触发、响应式和体感映射无回归；目视检查手机画面。再同步根目录单文件并发布到已有 GitHub Pages。
